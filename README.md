# Azure Enterprise Infrastructure

## Project Overview

This project demonstrates the deployment of a secure Azure enterprise environment using core Azure administration services.

## Architecture Components

- Resource Group
- Virtual Network
- Web Subnet
- Management Subnet
- Network Security Group (NSG)
- Windows Virtual Machine
- Azure Storage Account
- RBAC Role Assignments
- Azure Monitor Alerts
- Recovery Services Vault
- Cost Management Budget Alert

## Azure Services Used

- Azure Virtual Machines
- Azure Networking
- Azure Storage
- Azure RBAC
- Azure Monitor
- Azure Backup & Recovery
- Azure Cost Management

## Project Status

🚧 In Progress

## Goals

- Deploy a secure Azure environment
- Implement role-based access control
- Configure monitoring and alerts
- Configure backup and recovery
- Apply cost governance controls
- Document the complete architecture and deployment process
